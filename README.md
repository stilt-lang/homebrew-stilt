# Homebrew tap of Stilt

```sh
brew install stilt-lang/stilt/stilt
```

`Formula/stilt.rb` installs the toolchain of a [Stilt release](https://github.com/stilt-lang/stilt/releases)
on macOS on ARM and on Linux on ARM and x86-64. Each release writes it from its `SHA256SUMS`
(`tools/release/homebrew.py`), and it is copied here unchanged.
